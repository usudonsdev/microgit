保存したとき（Ctrl+S）

あなたが待つのは VS Code の保存だけ。MicroGit の記録は裏で順番に進みます。

あなた：Ctrl+S で保存
VS Code がファイルをディスクに書き、すぐに編集に戻れます。
裏で MicroGit に知らせる
MicroGit：保存を 1 回ずつ順番に処理
どのファイルが保存されたかを知っているので、そのファイルの分だけ処理します。
1履歴に残す
  • 停電に備えて、まず 1 か所に書く
    （確定を待つのは、ここ 1 回だけ）
  • Git と同じ形式のファイルを
    Git のプログラムを使わずに書く
Windows で約 25 ms（Git なら約 107 ms）
隠しリポジトリ（Git の履歴）
中身が変わった保存 1 回が、コミット 1 つに。
普通の Git でも読めます。
あなたのブランチやコミットは変わりません。
2戻るための準備
変わったファイルだけを
OverlayFS に「1 枚の差分」として積む
次に過去へ戻るときに、すぐ組み立てられる
OverlayFS（差分の重なり）
Windows・Mac では、拡張機能に入った
小さな Linux の中にあります。
消えても、Git の履歴から作り直せます。
保存が 0.3 秒落ち着いたら
画面（履歴のグラフ）を更新し、書いたファイルをまとめてディスクに確定させます。保存の待ち時間には入りません。
