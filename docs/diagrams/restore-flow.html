過去に戻るとき（履歴のグラフをクリック）

保存ごとの差分を重ねてその時点の姿を作り、確かめてから書き戻します。

あなた：履歴のグラフで、戻りたい保存の点をクリック
1途中の記録を確定させる
まだディスクに確定していない記録があれば、先に確定させます。
2その時点の姿を作る（OverlayFS）
その時点までの差分を重ねるだけで、
その時点のフォルダの姿ができます。
今の姿と比べて、変わったファイルを返します。
OverlayFS が使えないとき
Intel の Mac などでは、
v4 までと同じ方式（JavaScript）で
その時点の姿を組み立てます。
3書く前に確かめる（あなたの PC の上で）
  • .git の中や、作業フォルダの外には書かない
  • 受け取った中身が、記録と 1 バイトも違わないか
  • 全部受け取って確かめ終わるまで、作業フォルダには触らない
4作業フォルダに書き戻す
変わったファイルだけを書き、その時点に無いファイルを消します（消すのは MicroGit が記録したファイルだけ）。
かかる時間（ファイル 200 個、保存 40 回の履歴）
Mac で約 22 ms（普通の git checkout は約 29 ms）
Windows では約 170 ms（v4 までは約 1.4 秒）
